# Portafolio interactivo — Sol Margarit

Un recorrido por mis proyectos, habilidades y formación en desarrollo web. La navegación toma inspiración de los videojuegos: cada sección es una nueva zona para explorar.

## Explora

- **Proyectos:** trabajos personales y académicos, con detalles y enlaces a sus repositorios.
- **Habilidades:** lenguajes, frameworks, bases de datos y herramientas que forman parte de mi aprendizaje.
- **Formación:** estudios y cursos relacionados con desarrollo web y ciencia de datos.
- **Contacto:** formas de conectar conmigo.

## Tecnologías

HTML, CSS y JavaScript. El sitio es estático y no necesita instalar dependencias.

## Cómo verlo localmente

Desde la carpeta del proyecto, iniciá un servidor local:

```bash
python3 -m http.server 4173
```

Luego abrí [http://localhost:4173](http://localhost:4173) en el navegador. Para detenerlo, presioná `Ctrl+C` en la terminal.
